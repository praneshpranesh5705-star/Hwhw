# AgriConnect — Agriculture Portal

A responsive Next.js + Tailwind CSS agriculture portal prototype.

## Features

- Responsive navigation and landing page
- Crop guide with search
- Weather planning dashboard with demo data
- Indicative crop market-price table
- Mobile-friendly UI

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

> Weather and market values are demo data. Connect trusted APIs before using the portal for real-world decisions.
